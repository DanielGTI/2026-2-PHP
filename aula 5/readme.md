# Aula 5 — Manipulação de Arrays e Objetos em PHP

Este conteúdo apresenta os tipos de dados do PHP, arrays simples e associativos, funções para manipular arrays e uma introdução a objetos.

## Executar com Docker

Na pasta `aula 5`, execute:

```bash
docker compose up -d
```

Depois, abra [http://localhost:8083](http://localhost:8083).

Para encerrar os containers:

```bash
docker compose down
```

## Conteúdo da página

- Tipos escalares: `bool`, `int`, `float` e `string`;
- Tipos compostos: arrays e objetos;
- Tipos especiais: `null` e `resource`;
- Criação de arrays e acesso por chave/índice;
- `array_unique()`, `count()`, `asort()`, `arsort()`, `ksort()` e `krsort()`;
- Exemplos complementares de `array_push()`, `array_merge()`, `array_slice()` e `in_array()`;
- Criação e uso de um objeto com classe, propriedade e método;
- Atividade final com as respostas explicadas.

Os blocos de código possuem um botão para cópia e um link para o OneCompiler. Cada exemplo é autocontido e usa saídas de console (`echo` com `"\n"`), portanto pode ser colado e executado diretamente no compilador online.
